## 飽和警告（参入NG）

- Custom GPTs / GPT Store 単品販売（OpenAI 自身と競合・天井低い）
- Generic ChatGPT wrapper（90% が 2026 中に死ぬ予測・Margin 25-35%）
- Notion template / ChatGPT prompts PDF（2026 で市場崩壊済み）
- 動画生成 AI 大量量産（前段で除外指示通り）
- 一般 prompt 販売

## marketerへの一言

照井に最も合う上位は #8（AI Automation Agency）#12-13（Claude Code 受託）#5（Skool 3層）。
理由は「清掃20施設30人マネジメント」のアナログ経験と freee API・Claude Code 実装力が
そのまま単価 ¥5万-30万/月の retainer に化ける構造だから。

ただし照井の核（集約・もう一人の自分・気付けばそこにいる）と最も噛み合うのは
