## スレッド本文

[1/5] 個人サロン・教室の方からよく聞く話。予約のやり取りがLINE・DM・電話に分散していて、ダブルブッキングが怖い。これ、AIで一次受けに統一できます。
#AI活用 #個人事業

[2/5] before：LINEとDMと電話に予約が散る→紙の手帳に転記→転記漏れでダブルブッキング。月1回のヒヤリ。

[3/5]
```
あなたは予約調整アシスタントです。以下のメッセージから
1. 希望日時（複数候補ある場合は全部）
2. 氏名
3. メニュー
4. 連絡先
を JSON で抽出してください。曖昧な場合は「要確認」と書いてください。

メッセージ：{貼る}
```

[4/5] after：受け取ったメッセージをAIに投げる→構造化されて出る→そのままカレンダーに入れる。転記の事故がほぼゼロに。

[5/5] 「予約の散らばり」で消耗している方、整える順番を一緒に見れます → LINE @903xtesg
