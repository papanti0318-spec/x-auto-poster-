# Stock 02：清掃マニュアル作成

**トピック**: 業務マニュアル作成の自動化
**ベース事例**: 照井さんの清掃業務経験（一次経験）
**仮説ID**: thread_over_single, before_after_実例

## スレッド本文

[1/5] 軽井沢T-SITEで清掃業務を請けている。新人に渡すマニュアルを以前は半日かけて手書きで作っていた。いまは30分で初稿が出る。何を変えたかを書きます。
#AI活用 #業務改善

[2/5] before：頭の中の手順を思い出す→Wordに書く→順番が違うので並べ替え→写真貼る→半日。書いてる途中で現場に呼ばれて中断、また戻れない。

[3/5]
```
あなたはマニュアル作成のプロです。以下の作業を、未経験者が
1人で実施できるレベルで手順化してください。
- 各手順は1動作1行
- 注意点は「⚠」マークで併記
- 所要時間の目安を添える

作業内容：{ここに音声書き起こしを貼る}
```

[4/5] after：現場で作業しながらスマホに音声メモ→帰ってAIに投げる→初稿30分。あとは写真を差し込むだけ。「思い出す」工程がまるごと消えた。

[5/5] 「頭の中にある手順を文書化したい」方、一緒に整えられます → LINE @903xtesg
