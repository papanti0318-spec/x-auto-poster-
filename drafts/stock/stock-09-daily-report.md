**ベース事例**: 一次経験

## スレッド本文

[1/5] 日報を書くために1日の終わりに15分使っていた。いまは音声メモ1分→AIで3分。書く負荷が消えると、続けられる。
#AI活用 #日報

[2/5] before：終業後に思い出す→何をやったか曖昧→書き直す→疲れて雑になる→翌日読み返してもよくわからない。「日報のための日報」になっていた。

[3/5]
```
以下は1日の作業を音声で書き起こしたものです。次の構成で日報にしてください。
1. 今日の成果（3つまで）
2. 詰まったこと
3. 明日やること
4. 一言（学び）

書き起こし：{貼る}
```

[4/5] after：作業の合間に音声メモ→終業後にAIに投げる→3分で日報完成。読み返しても「あの日何やったか」がちゃんと残っている。
